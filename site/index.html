Everything a subnet needs

Subnet mask
The dotted-decimal mask for any CIDR prefix.

The total address count for any subnet size.

The broadcast address for any IP and prefix pair.
Wildcard mask
The inverse mask used in ACLs and routing protocols.
Host range
The first and last usable addresses in the subnet.
Binary netmask
The netmask in binary, for learning and review.
